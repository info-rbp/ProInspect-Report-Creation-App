# Appwrite Functions boundary

No remote Function is activated in this foundation phase. The first candidates are Shopify webhook intake, integration retry, reminder generation, reconciliation, housekeeping, and monthly Building Management report preparation.

AI, large PDF generation, document-heavy processing, and long-running jobs remain on Google Cloud. Any Function added here must use a least-privilege key, idempotency records, bounded execution time, redacted logging, and an explicit Development-first promotion plan.
